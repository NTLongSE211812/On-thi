📋 Bảng So Sánh Kinh Điển Hay Ra Trong Đề FE PRO192

Tóm tắt 1 trang
Cặp Khái Niệm Bên Trái Bên Phải
Overloading vs Overriding Overloading: Compile-time; cùng tên, khác danh sách tham số (cùng hoặc khác class). Overriding: Runtime; ở lớp con, cùng tên + tham số, modifier rộng hơn/bằng.
Abstract Class vs Interface Abstract Class: extends (đơn kế thừa), CÓ constructor, có biến instance thường. Interface: implements (đa kế thừa), KHÔNG constructor, field public static final, Java 8+ có default/static method.
String vs StringBuilder vs StringBuffer String: Immutable (bất biến), có String Pool. StringBuilder / Buffer: Mutable; Builder nhanh nhất (non-thread-safe), Buffer có synchronized (thread-safe).
Comparable vs Comparator Comparable<T>: Cài trong chính class, viết compareTo(T o) (1 tiêu chí mặc định). Comparator<T>: Tách riêng ngoài class, viết compare(T a, T b) (nhiều tiêu chí linh hoạt).
Checked vs Unchecked Exception Checked: IOException, SQLException — BẮT BUỘC try-catch hoặc throws lúc biên dịch. Unchecked: Con của RuntimeException (NPE, Arithmetic, ClassCast) — lỗi logic lúc chạy.
Byte Stream vs Character Stream Byte (8-bit): InputStream / OutputStream — ảnh, âm thanh, dữ liệu nhị phân. Character (16-bit): Reader / Writer — văn bản text Unicode (BufferedReader.readLine()).
